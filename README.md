# WJ Cleaners - Sistema de Gestão de Limpeza

Sistema completo de gestão comercial e operacional para empresas de serviços de limpeza, desenvolvido com React, TypeScript, Tailwind CSS e Firebase Firestore / Authentication.

## 🚀 Como Exportar e Conectar ao GitHub em 1 Clique

No menu superior do **Google AI Studio**:
1. Clique no menu **Export** / **Settings** (⚙️ no canto superior direito do AI Studio).
2. Selecione **Export to GitHub** (ou **Download ZIP**).
3. Autorize sua conta do GitHub e crie o repositório **`wj-cleaners`**.

---

## ⚡ Deploy Gratuito na Vercel

Este projeto já está 100% pré-configurado com `vercel.json` e arquivo de manifest PWA para publicação instantânea e gratuita na Vercel:

1. Acesse [vercel.com/new](https://vercel.com/new).
2. Importe o repositório **`wj-cleaners`** do seu GitHub.
3. Clique em **Deploy** (não é necessária nenhuma configuração de build especial).
